# Pengalaman Profesional — Tonjoo Gagas Teknologi

## System Analyst

Melakukan requirement gathering dan analisis workpaper untuk 4+ proyek digitalisasi enterprise (compliance, sustainability, recruitment), menghasilkan Functional Requirement dan User Story yang memastikan sign-off stakeholder tercapai sebelum development dimulai dan mengurangi pertanyaan ambigu dari tim development di awal sprint.

Merancang business process dan arsitektur data (ERD, swimlane, flowchart) untuk sistem multi-module dan multi-tenant, memastikan seluruh kebutuhan fungsional dan non-fungsional tercakup dalam dokumentasi teknikal sebelum development dimulai.

Membuat 50+ wireframe dan functional prototype sebagai dasar validasi UI/UX dengan stakeholder, mempercepat sign-off desain dari 2 minggu menjadi 3–5 hari.

Memecah kebutuhan bisnis menjadi 30–80+ User Story dengan Acceptance Criteria format Given-When-Then per proyek, menjadi acuan utama sprint planning dan QA testing sehingga requirement ambiguity hampir 0 saat masuk ke development.

Merancang REST API Specification dan melakukan integration testing (Postman/Bruno) pada endpoint 10–30+ per sistem, mengeliminasi bug integrasi sebelum masuk ke UAT.

Berkolaborasi dengan tim bisnis, development, UI/UX, dan QA dalam sprint 2 mingguan, memastikan setiap story yang masuk ke sprint sudah lolos review teknis dan bisnis.
